# Data Directory

Official NFL Big Data Bowl 2027 data is stored outside the Git repository at
`C:\GridironIQ-data\nfl-big-data-bowl-2027`.

```text
C:\GridironIQ-data\
  nfl-big-data-bowl-2027.zip
  nfl-big-data-bowl-2027\   Immutable extracted official CSVs
```

The raw archive and extracted CSVs are not tracked. Do not copy competition
files into the repository or redistribute them unless the official rules permit
it.

The pipeline records the source, retrieval date, listed and actual sizes,
SHA-256, headers, and access status in `reports/audit/data_inventory.md` and
`reports/audit/data_inventory.csv`.
